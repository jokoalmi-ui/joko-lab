## CONTENIDO (lo que dice)

### "A Quick Guide to Deep Learning Architectures" — Popular architectures and when to use them

7 arquitecturas con 3 campos cada una (What it does / Best for / Example Python):

| Arquitectura | Qué hace | Mejor para |
|---|---|---|
| **ANN** | Red básica que aprende patrones | Datos tabulares, clasificación, regresión |
| **CNN** | Capas convolucionales detectan características en imágenes | Clasificación de imágenes, detección de objetos, segmentación |
| **RNN** | Procesa secuencias donde el orden importa | Series temporales, modelado de lenguaje |
| **LSTM** | Puertas para dependencias a largo plazo | Lenguaje, series, dependencias largas |
| **GRU** | Menos compleja que LSTM, rendimiento similar | Entrenamiento rápido, eficiencia |
| **Autoencoder** | Representación comprimida de los datos | Reducción de dimensionalidad, detección de anomalías |
| **Transformer** | Atención para contexto en todas direcciones | NLP (BERT, GPT), traducción, generación, multimodal |

Tip final: "Elige la arquitectura según tu tipo de datos (tabular, texto, imágenes, vídeo)".
