# Análisis — Embudo de Ventas con Claude + Onepage AI (David Zamora, 16-ago-2026)

**Fuente:** https://youtu.be/WosyCcYKJdU (David Zamora, ~12 min, es)
**Transcripción:** completa (es)
**VERACIDAD:** [VERIFICADO]

## Qué es (resumen)

Embudo de ventas simple y efectivo para captar clientes por internet, montado
con IA (Claude + Onepage AI). Es el embudo real que el creador usa para su
comunidad "Inercia".

## El embudo (esquema)

```
Redes sociales / newsletter (tráfico)
        ↓ (enlace a landing, NO al producto)
Landing page con LEAD MAGNET (recopilación de prompts gratis)
        ↓ (formulario: email o teléfono + opt-in)
Página de gracias (descarga del lead magnet + presentación del producto)
        ↓
Producto (comunidad Inercia) → venta
```

Principios clave:
1. **El 90% de los que empiezan no usan estrategia** — solo página web + redes,
   esperando que pase algo. El embudo es lo que capta clientes.
2. **Lead magnet** = algo gratis que interesa (recopilación de prompts) a cambio
   del contacto. El suyo "está teniendo bastante éxito" (auto-declarado).
3. **La landing NO vende el producto directamente** — capta el lead primero;
   el producto se presenta en la página de gracias.
4. **Incluso si no compran**, ya tienes el contacto → campañas de newsletter,
   grupos de WhatsApp, etc.

## La tecnología (Claude + Onepage AI)

1. **Onepage AI**: app para crear landing pages, con capa gratuita, alojamiento
   incluido (sin hosting/dominio propio).
2. **Conector Onepage en Claude** (Claude Connect): autoriza tu cuenta → Claude
   crea las páginas con UN SOLO PROMPT (paleta de colores, tipografía, logo,
   formulario, secciones).
3. **Iteración por chat**: "ajusta el espaciado", "añade una sección con
   imágenes" → Onepage lo hace en segundos, siguiendo la paleta.
4. El prompt del creador está en su recopilación (lead magnet, otra vez).

## Relevancia para el LAB / Joseba

| Punto | Aplicación |
|---|---|
| **Plan de ingresos puente** | Embudo = mecanismo concreto para monetizar (LinkedIn Lab, productos, servicios) |
| **Lead magnet ya existente** | Joseba tiene material: infografías, análisis de vídeos, skills, recursos del lab — puede empaquetar algo gratis |
| **Landing page** | Conecta con el pipeline del lab (HTML/CSS propio, maurys, cuaderno) — aunque Onepage es cloud, el lab podría hacer landing estática local |
| **Automatización** | El lab ya tiene: Telegram, newsletter, contactos... el embudo encaja con lo que hay |
| **Cloud vs local** | Onepage es SaaS (choca con local-first); pero el CONCEPTO del embudo es lo valioso, la herramienta es intercambiable |

## Veredicto
**Muy relevante para monetización** — es el eslabón que faltaba entre "tengo un
lab que produce contenido" y "eso me genera clientes". El embudo es simple,
barato (capa gratis de Onepage) y probado por el creador. Para Joseba, el
lead magnet natural sería algo de su lab (recursos, infografías, análisis).
