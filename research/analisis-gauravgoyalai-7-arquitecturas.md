## Contenido: 7 arquitecturas de redes neuronales

| Arquitectura | Para qué sirve |
|---|---|
| Feedforward | Aprendizaje básico de patrones |
| CNN | Imágenes y patrones espaciales |
| RNN | Datos secuenciales |
| Transformer | Lenguaje y atención |
| Autoencoder | Compresión y detección de anomalías |
| GAN | Generación de datos sintéticos |
| Diffusion | Generación moderna de imagen y vídeo |

**Takeaway**: cada arquitectura → distinta fortaleza → distinto caso de uso.
