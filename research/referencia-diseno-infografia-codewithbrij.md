## 🎨 FORMATO VISUAL (para replicar en infografías del lab)

### Layout
- **Grid 4×3** (4 filas × 3 columnas = 12 celdas, una por concepto)
- Título centrado arriba + subtítulo (autor) debajo
- Orden lógico por filas:
  - Fila 1: RAG → Context → Memory (conocimiento externo → estado interno)
  - Fila 2: Agent → Agentic AI → Tools (capacidades del agente)
  - Fila 3: MCP → Skills → Hooks (herramientas, lógica reutilizable, triggers)
  - Fila 4: Subagents → Orchestration → Eval (descomposición, coordinación, medición)
- **Flechas discontinuas** (gris claro #6B7280) entre conceptos adyacentes indicando flujo

### Colores
- **Fondo**: neutro claro (#F8F9FA / off-white)
- **Acento principal**: azul (#2563EB) en subrayado del título
- **Iconos**: color variable por concepto (teal, marrón, azul, oro, verde, naranja, amarillo...)

### Tipografía (jerarquía)
- Título: sans-serif bold ~32px centrado (estilo Montserrat Bold)
- Subtítulo: sans-serif ligero ~16px
- Etiquetas de concepto: sans-serif medium ~18-20px (estilo Inter Medium)
- Descripciones: sans-serif ligero ~14px

### Detalles
- Bordes: 1px sólido gris claro sutil por celda
- Sombras: mínimas (profundidad sin recargar)
- **Sin numeración** — identificación solo por texto
- Filas uniformes (sin distinción visual entre superior/inferior)

## 💡 Aplicación al LAB

Este formato es REUTILIZABLE para:
1. **Infografías de LinkedIn Lab** (marca personal — el formato grid 4×3 con iconos es perfecto para contenido educativo)
2. **Ficha del perfume del día** (puede adoptar el grid de tarjetas si se quiere variar del formato v4 actual)
3. **Cualquier contenido educativo del lab** (12 conceptos = estructura ideal "4×3")

**Patrón clave**: 1 icono + 1 color por concepto + 1 línea de descripción + grid uniforme = formato limpio y replicable. Es la plantilla perfecta para el contenido de marca del lab (light theme, que es la preferencia del usuario para paneles).
