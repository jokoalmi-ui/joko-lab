# Análisis — Hi3D v3.0: generador de modelos 3D con IA (22-ago-2026)

**VERACIDAD:** [VERIFICADO]

**Fuente:** https://share.google/g002C1AoZP9Q84wkz → https://www.hi3d.ai/es (plataforma cloud, enlace compartido)
**Método:** navegación a la landing oficial + snapshot del contenido

## Qué es Hi3D v3.0
Plataforma **cloud de pago** de generación de modelos 3D con IA:
- **Texto → imagen → 3D** y **imagen → 3D** (modelo tridimensional listo para proyectos reales)
- **2048³ de resolución, 8K PBR** (texturas listas para producción)
- **Impresión 3D integrada**: dividir para imprimir, impresión multicolor, compatibilidad con Bambu/XTOOL/NetEase, exportación a laminador (slicer)
- **Plantillas**: figuras realistas, chibi, profesionales, mascotas, imanes de nevera, bloques
- **Próximamente**: "Hi3D imprime por ti" (servicio de impresión + envío a casa)
- **Modelo freemium**: 100 créditos gratis al registrarse, luego plan de pago
- **Prensa**: Reuters, AP, WSJ, Business Insider (cobertura mediática)

## 🔴 Para el LAB — VALOR: MEDIO-BAJO (interesante, pero cloud y no es core del lab)

| Aspecto | Análisis |
|---|---|
| ¿Generación 3D en el lab? | ❌ El lab NO tiene generación 3D hoy (tiene 2D: ComfyUI/SDXL + Manim) |
| ¿Local-first? | ❌ Es **cloud de pago** (créditos) — contradice el principio del lab |
| ¿Impresora 3D? | ❌ No consta que el lab/usuario tenga impresora 3D |
| ¿Utilidad potencial? | ⚪ Para contenido 3D (avatares, figuras, fichas con modelos 3D) si algún día se necesita |

**Conclusión honesta**: herramienta cloud interesante para quien hace modelos 3D o imprime en 3D — **no es el caso del lab hoy**. El lab genera 2D local (ComfyUI) y animación 2D (Manim); pasar a 3D requeriría impresora/uso cloud, que no está en el roadmap. Registrado como referencia de que existe (por si el usuario quiere hacer un muñeco 3D o similar), sin futurible de integración.

**Nota**: 100 créditos gratis podrían servir para una prueba puntual si el usuario quiere experimentar con 3D por curiosidad — pero no hay caso de uso real en el lab hoy.
