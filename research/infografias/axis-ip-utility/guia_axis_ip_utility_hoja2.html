Cámaras IP Axis · cuando IP Utility no la encuentra

Plan B: entrar por web
poniendo el portátil en su rango

La cámara se ha puesto una IP de otra subred. Le das al portátil una segunda dirección de esa subred, entras por navegador y desde dentro le pones la IP buena.

Por qué no se ven

1Mira qué IP tiene tu portátil y el nombre de la interfaz del cable. Linux: ip -br a · Windows: ipconfig. Apunta algo como eno1.
2Añade una segunda IP del rango de la cámara. No borres la que tienes. Elige el bloque según la versión de AXIS OS (lo viste en la hoja 1):
AXIS OS 12.0 o posterior · 169.254.x.x
sudo ip addr add 169.254.1.10/16 dev eno1
AXIS OS 11.11 o anterior · 192.168.0.90
sudo ip addr add 192.168.0.10/24 dev eno1
En Windows: IPv4 del adaptador → 169.254.1.10 máscara 255.255.0.0, o 192.168.0.10 / 255.255.255.0.
3Abre la web de la cámara con http:// delante. La IP exacta te la dice la lista de IP Utility aunque no puedas reasignarla. Si no la ves, prueba 192.168.0.90 a .95.
4Dentro de la cámara, ponle la IP de tu red real (y gateway y DNS) en su configuración de red IPv4. Guarda. Después limpia la dirección temporal: sudo ip addr del 169.254.1.10/16 dev eno1

Comprueba antes de entrar

ping -c 3 169.254.18.7 — si responde, el camino está bien. Si no responde, no te bloquees: hay cámaras que ignoran el ping y abren igual en el navegador. Prueba la web antes de dar nada por roto.

Ya dentro: IP buena
IP fija de tu red, gateway y DNS. Guarda y reconecta.
Contraseña nueva
La que creaste en el primer acceso. Nada de dejarla por defecto.
Hora por NTP
Sin hora correcta, las marcas de tiempo no sirven.

Si el portátil es Windows

Configuración → Red e Internet → Ethernet → Asignación de IP → Editar → Manual → IPv4: 169.254.1.10 con máscara 255.255.0.0 (o 192.168.0.10 / 255.255.255.0). Al terminar, vuelve a Automático (DHCP).

Siempre por cable
Por Wi-Fi el link-local es inconsistente. Ethernet del portátil o adaptador USB-C a RJ45.
Si conectas directo, inyector activo
Portátil ↔ cámara sin switch necesita inyector 802.3af/at. El PoE pasivo puede quemar el puerto.
Devuelve el adaptador a DHCP
Al terminar, quita la IP temporal o vuelve a automático. Si no, te quedas sin internet.
Fuente: documentación oficial de Axis, «How to assign an IP address and access your device» (abril 2026)
