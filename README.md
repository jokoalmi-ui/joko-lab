# Joko Lab

Laboratorio personal de automatización e inteligencia artificial.

**¿Qué es?** Un entorno local para diseñar, documentar y evolucionar soluciones de IA y automatización de forma incremental, reproducible y mantenible. Hermes Agent actúa como arquitecto técnico del laboratorio.

**¿Qué contiene?**
- Skills personalizadas para Hermes Agent
- Documentación del laboratorio
- Scripts y herramientas
- Registro de decisiones de arquitectura

**Documentos principales:**
- `HERMES.md` → identidad, principios y normas del laboratorio (fuente de verdad)
- `docs/arquitectura.md` → implementación técnica (hardware, software, servicios)
- `ROADMAP.md` → hoja de ruta del proyecto
- `docs/decisiones/` → registro de decisiones de arquitectura

**Para empezar:** leer `HERMES.md` para entender la filosofía, luego `docs/estado-real.md` para ver el estado actual del laboratorio.
