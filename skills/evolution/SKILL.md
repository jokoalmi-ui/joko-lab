# evolution — Skill de Evolution (correo, calendario, contactos)

## Propósito

Gestionar, diagnosticar y automatizar tareas relacionadas con Evolution, el cliente de correo y calendario de GNOME en el laboratorio.

## Contexto

- Versión instalada: 3.56.2-9
- Ruta del binario: /usr/bin/evolution
- Configuración: ~/.config/evolution/ (260K)
- Datos de correo y calendario: ~/.local/share/evolution/ (4.2 GB)
- Perfil configurado con libretas de direcciones, calendario y correo

## Cuándo usarla

- Cuando haya que diagnosticar problemas con Evolution (no arranca, no envía correo, calendario no sincroniza)
- Cuando se quieran hacer backups de los datos de Evolution
- Cuando se quiera integrar Evolution con n8n o automatizaciones
- Cuando se necesite documentar cuentas, perfiles o almacenamiento
