# betterbird

Skill para gestionar y automatizar Betterbird en Joko Lab.

## ¿Qué permite?

- Automatizar tareas de correo (filtros, respuestas, organización)
- Integrar Betterbird con n8n para flujos de correo automatizados
- Diagnosticar problemas de configuración de cuentas

## ¿Qué NO permite?

- No acceder a credenciales de correo sin autorización
- No modificar configuraciones de cuentas sin confirmación

## Dependencias

- Betterbird instalado en el sistema
- (Opcional) n8n para flujos de automatización de correo

## Estado actual

Betterbird está instalado pero **NO activo**. El cliente de correo activo actualmente es **Evolution**.
