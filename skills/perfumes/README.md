# perfumes

Skill para gestionar conocimiento sobre perfumes, fragancias y consultas relacionadas.

## ¿Qué permite?

- Consultar información sobre perfumes y fragancias
- Gestionar un catálogo personal de perfumes
- Responder preguntas sobre notas, familias olfativas y recomendaciones

## ¿Qué NO permite?

- No recomendar perfumes sin suficiente información de contexto
- No inventar datos sobre perfumes que no estén confirmados

## Dependencias

- (Por determinar) Posible base de datos local o archivo de conocimientos
