# hermes-expert

Skill para que Hermes se conozca a sí mismo.

**Etapa actual:** 2 — Diagnosticar

## ¿Qué permite?

- Conocer la estructura real de Hermes (~/.hermes/)
- Entender la configuración del agente (modelo, proveedor, toolsets, personalidades)
- Diagnosticar límites y comportamientos del sistema
- Llevar un registro cronológico de descubrimientos
- Auditar qué partes de Hermes quedan por explorar

## Archivos

| Archivo | ¿Qué contiene? |
|---|---|
| STRUCTURE.md | Árbol completo de ~/.hermes/ con explicación de cada carpeta |
| CONFIG.md | Detalle de config.yaml: cada opción, su valor y notas |
| KNOWLEDGE.md | Cómo funciona Hermes internamente (modelo, skills, memoria) |
| COMMANDS.md | Comandos útiles para explorar y diagnosticar Hermes |
| LIMITATIONS.md | Límites reales encontrados (verificados, con fecha) |
| DIARY.md | Diario cronológico de descubrimientos por sesión |
| AUDIT.md | Checklist de verificación con ✔ ✖ ? |

## ¿Qué NO permite?

- No modificar config.yaml sin confirmación explícita
- No modificar SOUL.md sin explicar el impacto
- No asumir información no verificada
