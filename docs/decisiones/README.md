# Registro de decisiones

Este directorio contiene las decisiones importantes tomadas durante el desarrollo de Joko Lab.

Cada decisión se almacena en un archivo independiente para facilitar su consulta.

Formato: AAAA-MM-DD-tema.md

Cada documento debe contener:

- Contexto
- Problema
- Alternativas consideradas
- Decisión adoptada
- Motivos
- Consecuencias
- Estado (vigente, reemplazada, descartada)
