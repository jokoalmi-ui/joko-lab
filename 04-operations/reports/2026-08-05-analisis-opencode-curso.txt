## Qué es

Curso completo en directo sobre **OpenCode** — la alternativa open source a
Claude Code. Instructor "Bris" (español). OpenCode: **191K estrellas GitHub**
(~1000 contribuidores), comparado con Claude Code 140K — "más apoyado por la
comunidad open source que un proyecto respaldado por una empresa con billones".

## Puntos clave del curso (aplicables al lab)

### 1. Proveedores: 75+ y modelos locales GRATIS
- OpenCode soporta **más de 75 proveedores** (Anthropic, OpenAI, Google, etc.)
- **Modelos locales 100% gratis** — se puede enganchar Ollama / LM Studio
- Plan free de OpenCode Zen incluye: **Pickel, Dixic, Nemotron, North Mini,
  Laguna, Link, DeepSeek** — modelos gratuitos integrados
- Al seleccionar modelo se elige "esfuerzo" (razonamiento): más esfuerzo =
  más lento pero más inteligente, más tokens

### 2. Commands personalizados (comandos)
- Directorio `.opencode/command/`
- Estructura: `descripción` + `agente` (build/plan) + `prompt`
- Ejemplo del curso: comando `/commit` → "genera un commit siguiendo las
  convenciones del proyecto" con `git diff --staged`
- **Aplicación al lab:** crear comandos personalizados para los flujos del lab
  (ej: `/joko-commit` con las convenciones de joko-git-recibos)

### 3. Skills (habilidades)
- Directorio `.opencode/skill/`
- Estructura similar a las skills de Hermes: nombre + descripción + prompt
- El agente las crea solo: "crea una skill a nivel de proyecto para ejecutar
  los tests" → crea la skill + instala dependencias + verifica
- **Aplicación al lab:** el concepto de skill de OpenCode = skill de Hermes —
  el lab ya domina este patrón

### 4. Modelos locales
- El curso dedica sección a "cómo ejecutar Open Code con modelos en local"
- Cada vez más importante; útil para tareas donde un modelo local pequeño
  tiene sentido
