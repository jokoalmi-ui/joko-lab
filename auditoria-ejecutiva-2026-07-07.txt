======================================================================
1.  ¿QUÉ ES JOKO LAB?
======================================================================

Joko Lab es un laboratorio personal de ingeniería asistida por IA.

No es un simple proyecto de automatización. Es un entorno diseñado
para diseñar, documentar, operar y evolucionar infraestructura técnica
de forma incremental, reproducible y comprensible.

Hermes Agent actúa como arquitecto técnico del laboratorio: utiliza
documentación estructurada y skills especializadas para ayudar a tomar
decisiones, detectar mejoras y mantener el conocimiento del sistema
a lo largo del tiempo.

El laboratorio funciona sobre un equipo de escritorio local, con
servicios en contenedores Docker, modelos de IA instalados localmente
(y uno online como respaldo), y un asistente (Hermes) que orquesta
todo el entorno.

No depende de la nube para sus funciones principales. Los datos
sensibles se procesan localmente.


======================================================================
2.  ¿QUÉ PROBLEMA RESUELVE?
======================================================================

El problema de base es: mantener un sistema técnico que crece con el
tiempo sin que se vuelva incomprensible, frágil o dependiente de una
sola persona.

Joko Lab resuelve esto con tres mecanismos:

  1. Documentación estructurada — cada decisión, cada cambio, cada
     componente tiene un archivo que explica qué es, por qué está ahí
     y cómo se relaciona con el resto.

  2. Skills especializadas — Hermes Agent no es un asistente genérico.
     Tiene skills que lo especializan en áreas concretas: Docker, n8n,
     modelos de IA, diagnóstico. Cada skill documenta su propio
     conocimiento, comandos y límites de seguridad.

  3. Director Técnico (lab-manager) — una skill que audita, diagnostica
     y prioriza. No ejecuta acciones, pero responde preguntas como
     "¿cuál es la deuda técnica?", "¿qué ha cambiado?", "¿qué
     reconstruirías primero?".

El laboratorio se rige por cinco principios:

  1. Comprender antes de actuar
  2. Verificar antes de afirmar
  3. Documentar las decisiones importantes
  4. Priorizar soluciones simples y mantenibles
  5. Mejorar continuamente

5.  INTELIGENCIA ARTIFICIAL
======================================================================

Joko Lab tiene tres proveedores de IA, con un árbol de decisión que
selecciona automáticamente cuál usar según la tarea:

  ┌─ ¿Datos privados? ──────────────────────→ Ollama (local)
  │   ├─ ¿Multimodal (imagen/video)? ──────→ LM Studio (local)
  │   └─ ¿Razonamiento complejo? ──────────→ DeepSeek (online)
  │       └─ ¿Consulta simple? ────────────→ Ollama (local)

  Proveedor       |  Tipo        |  Endpoint                 | Modelos
  ----------------|--------------|---------------------------|-------------------------
  DeepSeek Flash  |  Online      |  DeepSeek API             | v4-flash
  Ollama          |  Local       |  localhost:11434          | qwen2.5:7b,
                  |              |                           | llama3.1:8b,
                  |              |                           | llama31-8b-64k
  LM Studio       |  Local       |  localhost:1234           | gemma-4-e4b,
                  |              |                           | gemma-4-12b-qat,
                  |              |                           | gemma-4-12b,
                  |              |                           | glm-4.6v-flash,
                  |              |                           | qwen/qwen3.5-9b,
                  |              |                           | text-embedding-nomic

Además, hay un router de IA llamado ai-router que decide automáticamente
qué proveedor usar según el tipo de consulta (datos privados → local,
tareas rápidas → gemma-4-e4b, razonamiento detallado → gemma-4-12b-qat,
visión → LM Studio).

Hermes Agent (el asistente principal) usa DeepSeek Flash como proveedor
predeterminado.

  ---  DETALLE DE CADA SKILL  ---

  docker-admin (v0.4.0, Etapa 4)
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
  Gestiona el stack Docker del laboratorio. Sus scripts permiten:
  - healthcheck.sh: verifica que todos los servicios estén activos
  - backup-volumen.sh: realiza copias de seguridad de volúmenes Docker
  - restore-volumen.sh: restaura volúmenes desde backups
  - install-cron.sh: instala tareas programadas (cron)
  - auditar-stack.sh: auditoría completa del stack Docker
  Skill madura y completa. Es la skill más avanzada del laboratorio.

  hermes-expert (v0.3.0, Etapa 4)
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
  Diagnóstico y configuración de Hermes Agent. Sus scripts:
  - hermes-diag.sh: diagnóstico del estado de Hermes
  - detect-config-changes.sh: detecta cambios en la configuración
  - install-system-crons.sh: instala crons del sistema
  Skill madura y completa.

  ai-router (v0.4.0, Etapa 3)
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~
  Enrutador inteligente de modelos de IA. Contiene:
  - ai-router.py: selecciona automáticamente el modelo según la tarea
  Árbol de decisión: datos privados → Ollama, visión → LM Studio,
  razonamiento complejo → DeepSeek, simple → Ollama.
  Funcional y estable. Pendiente de integrar completamente en Hermes.

  n8n-admin (v0.3.0, Etapa 3)
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~
  Gestión de n8n, la herramienta de automatización. Sus scripts:
  - healthcheck-n8n.sh: verifica el estado de n8n (5 tests)
  - export-workflows.sh: exporta workflows de n8n
  n8n tiene RAM 2 GB, healthcheck cada 30 min, y un workflow activo
  llamado "ENVIO WHATSAPP".

  lab-manager (v0.2.0, Etapa 2) — Director Técnico
  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~
  Skill más reciente. Es el Director Técnico del laboratorio:
  - diagnosticar.sh: genera un snapshot completo del estado
  - deuda-tecnica.sh: calcula y cuantifica la deuda técnica
  - cambios-ultima.sh: compara el estado actual con la última auditoría
  - priorizar.sh: propone orden de reconstrucción y prioridades
  Recién ascendida a etapa 2. Pendiente de auditoría y optimización.
