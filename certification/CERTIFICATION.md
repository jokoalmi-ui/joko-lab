# Certificación de Arquitectura de Joko Lab

Versión: 1.0
Estado: Vigente

---

## Resumen

La certificación de arquitectura verifica que un agente (IA o humano) comprende,
mantiene, evoluciona y gobierna Joko Lab utilizando exclusivamente la documentación
del proyecto. Consta de casos independientes agrupados por competencias.

---

## Competencias (C1-C9)

| ID | Competencia | Propósito |
|----|-------------|-----------|
| C1 | Comprensión | Interpretar correctamente la documentación |
| C2 | Auditoría | Inspeccionar el estado del laboratorio |
| C3 | Arquitectura | Diseñar estructuras mantenibles |
| C4 | Evolución | Prever el impacto de cambios futuros |
| C5 | Operación | Conocer el funcionamiento del laboratorio |
| C6 | Recuperación | Actuar ante errores |
| C7 | Seguridad | Proteger el laboratorio |
| C8 | Gobierno | Mantener el conocimiento del laboratorio |
| C9 | Mentoría | Explicar el laboratorio a otros |
