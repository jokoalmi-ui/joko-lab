# Rúbrica de Evaluación — Certificación de Arquitectura de Joko Lab

Versión: 1.0
Estado: Vigente

---

## Estructura de evaluación

Cada caso de certificación (C-XXX) se evalúa con 5 criterios.
Cada criterio se puntúa de 1 a 5.
Puntuación máxima por caso: 25 puntos.

---

## Criterios

### Comprensión

Mide si el agente entiende correctamente el problema planteado.

| Puntos | Descripción |
|--------|-------------|
| 1 | No entiende la pregunta. Responde otra cosa. |
| 2 | Entiende parcialmente. Omite detalles clave del enunciado. |
| 3 | Entiende correctamente el problema. No añade ni omite nada relevante. |
| 4 | Entiende el problema y además identifica implicaciones no explicitadas. |
| 5 | Entiende el problema en su contexto completo, relacionándolo con otras partes del laboratorio. |

### Razonamiento

Mide si las conclusiones están justificadas.

| Puntos | Descripción |
|--------|-------------|
| 1 | Afirma sin justificar. |
| 2 | Justifica parcialmente. Argumentos débiles o imprecisos. |
| 3 | Justifica con referencias a la documentación. Argumentos coherentes. |
| 4 | Justifica con documentación y además compara alternativas. |
| 5 | Justifica con documentación, compara alternativas y explica por qué descarta las no elegidas. |

### Coherencia

Mide si la respuesta contradice la documentación del laboratorio.

| Puntos | Descripción |
|--------|-------------|
| 1 | Contradice directamente la documentación. |
| 2 | Alguna afirmación no se sostiene con la documentación existente. |
| 3 | No contradice la documentación. Todo lo dicho es verificable. |
| 4 | Además de no contradecir, refuerza la documentación con referencias cruzadas. |
| 5 | Detecta y señala incoherencias en la propia documentación si existen. |

### Priorización

Mide si el agente ordena correctamente las acciones cuando la pregunta lo requiere.

| Puntos | Descripción |
|--------|-------------|
| 1 | No prioriza. Todo parece igual de urgente. |
| 2 | Prioriza pero sin criterio claro. |
| 3 | Prioriza con criterio justificado (urgencia, dependencia, impacto). |
| 4 | Prioriza y además identifica dependencias entre acciones. |
| 5 | Prioriza, identifica dependencias y propone un plan secuenciado. |

### Visión global

Mide si el agente relaciona distintas partes del laboratorio.

| Puntos | Descripción |
|--------|-------------|
| 1 | Responde de forma aislada. No relaciona nada. |
| 2 | Relaciona algún elemento pero de forma superficial. |
| 3 | Relaciona varios elementos del laboratorio de forma coherente. |
| 4 | Relaciona elementos y detecta implicaciones entre ellos. |
| 5 | Relaciona todos los dominios (docs, skills, scripts, certificación) como un sistema. |

## Niveles de madurez por puntuación

| Rango | Nivel | Nombre |
|-------|-------|--------|
| 0-9 | 0 | No apto |
| 10-14 | 1 | Comprende |
| 15-18 | 2 | Diagnostica |
| 19-21 | 3 | Diseña |
| 22-24 | 4 | Optimiza |
| 25 | 5 | Gobierna |

---

## Evaluación global

La certificación se compone de varios casos.
La puntuación global es la media de todos los casos evaluados.

| Media global | Nivel global |
|-------------|--------------|
| 0-9 | No certificado |
| 10-14 | Nivel 1 — Comprende |
| 15-18 | Nivel 2 — Diagnostica |
| 19-21 | Nivel 3 — Diseña |
| 22-24 | Nivel 4 — Optimiza |
| 25 | Nivel 5 — Gobierna |
